# Configuration

L’installateur produit un vrai fichier `omnistream.json` avec les chemins résolus sur le poste. Le schéma `omnistream.schema.json` décrit son format. Aucun fichier de configuration prérempli avec des chemins fictifs n’est distribué.

Voir `docs/CONFIGURATION.md` pour la localisation et les paramètres. Les commandes de diagnostic lisent la configuration réelle ; ne pas copier un exemple JSON avec des chemins non résolus.
